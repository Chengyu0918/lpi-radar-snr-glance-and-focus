# 使用COCO数据集测试AdaptiveNN

## 📋 概述

COCO (Common Objects in Context) 是一个大规模的目标检测、分割和图像标注数据集。我们将使用COCO数据集来测试AdaptiveNN模型，验证环境配置是否正确。

---

## 第一步：下载COCO数据集

### 方法1：使用官方下载脚本（推荐）

COCO数据集较大，建议下载较小的验证集进行测试：

```bash
# 创建数据目录
mkdir coco_data
cd coco_data

# 下载2017验证集图像（约1GB）
wget http://images.cocodataset.org/zips/val2017.zip

# 下载标注文件（约241MB）
wget http://images.cocodataset.org/annotations/annotations_trainval2017.zip

# 解压
unzip val2017.zip
unzip annotations_trainval2017.zip
```

### 方法2：使用Python脚本下载（Windows友好）

我已为您创建 `download_coco.py` 脚本（见下文）

### 方法3：手动下载

访问 [COCO官网](https://cocodataset.org/#download) 下载：
- 2017 Val images [5K/1GB] - 验证集图像
- 2017 Train/Val annotations [241MB] - 标注文件

---

## 第二步：准备数据集结构

```

│   └── ...
└── annotations/          # 标注文件
```

## 第三步：转换为ImageFolder格式

AdaptiveNN使用PyTorch的ImageFolder格式，需要将COCO转换为分类任务格式。

### 选项A：使用COCO的80个类别

运行转换脚本 `convert_coco_to_imagefolder.py`（见下文）

### 选项B：简化测试 - 使用子集

为了快速测试，可以只使用部分类别（如10个类别）

| 数据集 | 类别数 | 图像数 | 大小 | 下载时间 |

| COCO Val2017 | 80 | 5,000 | ~1GB | 5-15分钟 |

## 常见问题

### Q1: COCO数据集太大，下载太慢
**解决方案**：
- 只下载验证集（1GB）而不是训练集（18GB）
- 使用国内镜像源
- 或直接使用您的雷达信号数据（更小更快）

### Q2: 如何转换COCO为分类格式
**解决方案**：
- 使用提供的转换脚本
- 或使用现成的ImageNet格式数据集
- 或直接使用雷达信号数据（已是正确格式）

### Q3: 想快速验证环境
**解决方案**：
建议直接使用雷达信号数据：
1. 数据量小（16,000张 vs COCO的118,287张）
2. 已是正确格式（无需转换）
3. 训练快（100 epochs约5-8小时）
4. 更符合您的实际需求
